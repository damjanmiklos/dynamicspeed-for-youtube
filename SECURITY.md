# Security Policy

## Supported Versions

We actively release security patches and updates for the latest extension version across supported browsers.

| Version | Supported          |
| :------ | :----------------- |
| Latest  | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

If you discover a potential security vulnerability within **DynamicSpeed for YouTube**, please report it responsibly so we can resolve it before public disclosure.

### How to Report

Use [GitHub Private Vulnerability Reporting](https://github.com/damjanmiklos/dynamicspeed-for-youtube/security/advisories/new) directly on this repository.

### What to Include in Your Report

To help us investigate and reproduce the issue quickly, please provide:
1. A clear description of the vulnerability and its potential impact.
2. Steps to reproduce the issue (including sample video URLs or reproduction scripts).
3. Browser environment details (e.g., Chrome v128, Firefox v130, OS).
4. Any proposed fixes or mitigation strategies (if available).

---

## Response Timeline & Handling

* **Initial Acknowledgment:** Within **48–72 hours** of receiving the report.
* **Triage & Status Update:** Within **7 days** with an assessment of the vulnerability.
* **Fix & Release:** We aim to release a patch and push an update to browser extension stores as quickly as feasible depending on severity.

Please do not open public GitHub Issues or Discussions for undisclosed security vulnerabilities.
